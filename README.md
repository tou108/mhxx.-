# 頑シミュ MHXX Android版

モンスターハンターダブルクロス (MHXX) のスキルシミュレータのAndroidアプリです。

## ビルド方法

### GitHub Actionsでビルド (推奨)
1. このリポジトリをGitHubにプッシュ
2. Actionsタブ → "Build APK" → "Run workflow"
3. 完了後、Artifactsから `app-debug.apk` をダウンロード

### ローカルでビルド
Android Studio をインストールし、プロジェクトを開いて "Run" または "Build APK"

## 機能
- スキル検索（最大5スキル同時指定）
- 剣士/ガンナー・性別フィルター
- 装飾品の自動計算
- 防具一覧・装飾品一覧

## データ
- 頑シミュ MHXX ver.0.9 (2017/3/26) のデータを使用
- 防具: 頭/胴/腕/腰/脚 各約1200種
- スキル: 326種
- 装飾品: 242種
